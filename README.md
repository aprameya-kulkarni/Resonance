RESONANCE-1 is a programmable sensor-processing SoC designed to acquire, process and analyze vibration data from a physical system. The system performs configurable digital signal processing and extracts features from the vibration spectrum to identify deviations from a learned baseline. The system is designed to demonstrate an end-to-end ECE/semiconductor development flow from physical sensing and analog conditioning through digital processing, embedded computation, verification, PCB design and ASIC implementation.
